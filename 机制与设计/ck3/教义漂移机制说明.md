## 一、现象

你在玩 867 年的拜占庭。开局信希腊礼，核心信条是：

```
教权制（tenet_pentarchy）
天使品级（tenet_celestial_hierarchy）
事奉圣礼（tenet_divine_liturgy）
```

然后过了几年，什么都没干，第三条变成了：

```
圣洁自然（tenet_sanctity_of_nature）
```

效果是：解锁「保护荒野」决议、允许祝圣动物饰品、森林优势 +5、森林征召 +20%。

**一个自称「使徒所传、从不改变」的教会，开始信自然了。**

而且——**没有任何提示。** 没有信件，没有事件，没有弹窗。

## 二、机制：它是怎么发生的

### 1. 年度脉冲

`on_rite_yearly` 每年给每个礼掷一次骰子（`pam_effects.txt:6511-6552`）：

```paradox
random = {
    chance = {
        value = 4                                        # 基础 4%
        if = { limit = { faith.fervor <= @hor_drift_low_fervor }        add = 6 }
        if = { limit = { faith.fervor >= @hor_drift_high_fervor }       add = -2 }
        if = { limit = { head_of_rite ?= { spiritual_fulfillment <= 0 } } add = 4 }
        if = { limit = { head_of_rite ?= { has_trait = heresiarch } }   add = 25 }
        min = 1
    }
    rite_yearly_hor_divergence_drift_apply_effect = yes
}
```

**注意最后那行：礼仪领袖如果是「异端创始者」（heresiarch），概率直接 +25。**

### 2. 一年漂几次

算术很简单：`1 - (1-p)^年数`。

| 年概率 | 20 年至少一次 | 30 年至少一次 | **30 年期望次数** |
|---|---|---|---|
| 4%（高热忱） | 55.8% | 70.6% | **1.2 次** |
| **10%（典型）** | 87.8% | 95.8% | **3.0 次** |
| 29%（礼仪领袖是异端创始者） | 99.9% | 约 100% | **8.7 次** |

**典型配置下，一位皇帝 30 年任期的期望是「漂三次」。**

这跟运气无关，是设计的中位数。

### 3. 漂多大、漂到哪

`rite_yearly_hor_divergence_drift_forward_pick_effect`（`pam_effects.txt:6643-6722`）：

```paradox
random_list = {
    1 = { ... divergence <= 20 ... step_high   ... override_tenets_first = no  }
    1 = { ... divergence <= 20 ... step_high   ... override_tenets_first = yes }
    3 = { ... divergence <= 30 ... step_normal ... override_tenets_first = no  }
    3 = { ... divergence <= 30 ... step_normal ... override_tenets_first = yes }
    8 = { ... divergence <= 40 ... step_low    ... override_tenets_first = no  }
    8 = { ... divergence <= 40 ... step_low    ... override_tenets_first = yes }
}
```

两个细节：

- **偏离度低则步子大；偏离度高则步子小；超过 40 时前进通道直接关闭。** 这部分其实是有阻尼的。
- **`override_tenets_first = no / yes` 是 50/50 的抛硬币** —— 决定「先换信条还是先改偏离度」。

因为信条是从**按偏离度过滤的池子**里抽的，所以先改还是后改，**会抽到不同的东西**。

> **同一个偏离度变化，扔一次硬币，结果可能是两个完全不同的教义。**

### 4. 池子是哪儿来的

抽卡池 = `christian_faith` 的 `permitted`（可采纳）清单，写死在 `history/faiths/00_christianity.txt:13-32`：

```paradox
permitted = {
    tenet_vows_of_poverty      tenet_communal_identity
    tenet_asceticism           tenet_pentarchy
    tenet_adaptive             tenet_sanctity_of_nature     # 圣洁自然就在这
    tenet_divine_liturgy       tenet_anachoresis
    ...
}
```

**18 条，一张扁平清单。** 修院苦修、自然崇拜、生育繁衍、基督的士兵——平权。

## 三、为什么「圣洁自然」这事特别荒唐

查一下全游戏各信仰对它的态度（`history/faiths/*.txt`）：

| 信仰 | 地位 |
|---|---|
| **christian_faith（含希腊礼）** | **允许（permitted）** |
| **orthodox（东正教）** | **允许（permitted）** |
| catholic（天主教） | 仅已知（known） |
| **各多神教**（巴斯克、芬兰、西非、藏缅…） | **仅已知（known）** |
| 佛教 / 印度教 / 伊斯兰 / 道教 / 琐罗亚斯德 | 仅已知 |

**看懂了吗：多神教自己都不能把「自然崇拜」当核心信条。只有希腊礼和东正教能。**

游戏界面上也写着（打开宗教页面就能看到）：

```
圣洁自然
在迦克墩基督教中的信条地位: 允许
```

**所以别怪骰子。骰子只是执行者，授权的是那张清单。**

## 四、四个结构性问题

### (1) 标量冒充向量

867 年的东西方差异，是一张**列举得出来的清单**：

| 争点 | 罗马 | 君士坦丁堡 |
|---|---|---|
| 和子句（Filioque） | 有 | 无 |
| 教宗首席权 | 承认 | 不承认 |
| 圣餐饼 | 无酵 | 有酵 |
| 教士婚姻 | 全禁 | 禁主教、许司铎 |
| 炼狱 | 有 | 无 |
| 划十字方向 | 左到右 | 右到左 |

**每一条都是独立的是/否。这是六维向量。**

而游戏把它压成了一个整数 `divergence`（0-100）。

> **一个被压缩成标量的系统，只能用随机数来「解释」这个标量。**

有意思的是，P社 在**文化系统**里做对了：文化融合有 ethos + traditions + pillars 组成的特征空间，分歧是空间里的距离，融合是沿空间插值。**文化有向量，礼只剩一根标尺。**

### (2) 抽样不看方向

漂移只有两个匿名方向：`forward` / `backward`。**但抽信条时不看方向、不看目标**——从同一个池子里随机抓。

所以「漂到斯拉夫礼」在机制上真的可能——**不是因为它朝斯拉夫礼走，是因为它朝随机走。**

### (3) 没有记录的地方

这是最要命的。整个变更过程唯一的痕迹是 `debug.log` 里的一行：

```
[14:26:34][D][rite_effects.cpp:755]: [RiteGen] Swapped out tenet
  tenet_divine_liturgy for tenet tenet_sanctity_of_nature
  while changing Rite with target divergence change 15.
```

- 没有发起者
- 没有裁决者
- 没有决议文本
- 没有公示对象

### (4) 而且通知名单里把你排除了

P社 **写了**通知函数（`pam_effects.txt:6842`），注释还写着：

> `# Notify every ruler of the rite + the religious head, via letter event.`

```paradox
every_faith_ruler = {
    limit = {
        rite = scope:diverged_rite
        this != scope:diverged_hor        # 排除礼仪领袖
    }
    trigger_event = pam_tenet_events.0004
}
# Religious head (if any) gets the letter too, even if they are not iterated above.
faith.religious_head ?= {
    if = {
        limit = {
            NOT = { rite = scope:diverged_rite }   # 只有礼不同才补发
            this != scope:diverged_hor             # 又排除一次
        }
        trigger_event = pam_tenet_events.0004
    }
}
```

**两个分支都排除了 `diverged_hor`。注释承诺要通知的那个人，代码里排了两次。**

> **教义被换掉的那位本人，是唯一收不到信的人。**

## 五、真实的东正教是怎么搞的

最好的样本是**圣像破坏运动**（726-843）。它是拜占庭史上最大的一次教义变动，而且过程完整留档。

### 完整时间线

| 年 | 谁 | 做了什么 |
|---|---|---|
| 726 | **利奥三世** | 颁布禁止圣像的诏令（皇帝发起） |
| 754 | **君士坦丁五世** | 召集**海尔利亚会议**，宣布圣像崇拜为异端 |
| 787 | **伊琳娜 + 牧首塔拉修斯** | **第二次尼西亚公会议**，恢复圣像 |
| 815 | **利奥五世** | 圣索菲亚会议，再度破坏 |
| 843 | **狄奥多拉 + 牧首美多迪乌斯** | 宗教会议，**正统凯旋**，圣像永久恢复 |

### 关键：合法性由谁追认

**754 那次会议，皇帝召集、规模宏大、决议明确——被后世判定为伪公会议。**

而 787 的尼西亚二世，被承认为**第七次大公会议**。

> **皇帝能召集，不能定义。**
> **会议的追认才是教义合法性的来源——而「哪次会议算数」，本身由教会判定。**

**一次皇帝全力推动的教义变更，最后被推翻了。**

### 843 留下了一个东西，正好戳中游戏的缺口

**《正统礼典》（Synodikon of Orthodoxy）**——它不是一次性事件，是**每年大斋期第一主日当众宣读的宪制文件**。

内容是：谁被纪念，谁被诅咒（anathema）。**一份名录。**

=> **东正教的教义变更必须写进一份每年重读的文本里。**

**所以东正教里根本不存在「可以悄悄变的教义」这个位置。** 任何变更都要上名录，而名录年年当众朗读——**它藏不住。**

## 六、两张表对照

### 教义变更的合法程序

| | 真实东正教 | CK3 |
|---|---|---|
| 谁发起 | 皇帝 / 牧首 / 修士团体 | 无（引擎自动） |
| 程序 | 召集 -> 议程 -> 议决 -> 颁布 | `random_list` 抽中 |
| 谁裁决 | 大公会议 / 宗教会议 | 无 |
| 合法性来源 | 会议追认 | 无 |
| 留痕 | 决议文本 + 名录（年年重读） | `debug.log` 一行 |
| 失败会怎样 | 变成异端、被定罪 | 不发生，无声无息 |
| 皇帝能否单方面定 | **不能**（754 是前车之鉴） | **能——但只有 4%/年** |

### 变更的粒度

| | 真实东正教 | CK3 |
|---|---|---|
| 礼仪（有酵饼、划十字方向、语言） | **会变，且可以合法地变** | 归在同一个 `rite` 对象里 |
| 核心信条（使徒所传、七次大公会议） | **不变** | 和礼仪一起被随机漂移 |

**P社 把「可变的礼仪」和「不可变的教义」塞进同一个对象，然后对它施加统一的随机漂移。**
