## 问题

原版把「拜占庭牧首任免」卡在 `piety_level >= 3`
（`pam_interactions.txt:2461` `request_realm_priest_replacement_interaction`）。

- 巴西尔一世 867 年刺杀米海尔三世登基，piety 必然很低；
- 而他登基后的第一批动作之一就是换牧首（废佛提乌、复立印纳提俄斯）；
- 游戏把「给篡位者合法性」的动作，卡在他没时间积累的「个人虔诚」上。

根因：把授职权之争的西方模型（虔诚换谈判资格）套到拜占庭（机构权力）。

## 设计

**拜占庭特判：条件 = 希腊礼 + 行政制；货币 = 影响力，不是虔诚。**

| 环节 | 内容 |
|---|---|
| 门槛 | `rite = rite:byzantine_rite` 且 `government_has_flag = government_is_administrative` |
| 定价 | 影响力（`influence`），而非 `piety_level` |
| 额外代价 | 全体内阁成员 `add_opinion` 负修正符（如 −20，10 年） |
| 其余 | 完全走原版：候选池、点名（`scope:secondary_recipient`）、5 年冷却 |

### 为什么不是「绕开门槛」

| | 绕开 | 本设计 |
|---|---|---|
| 代价货币 | 无 | 影响力 + 政治资本 |
| 与政体匹配 | 否 | 是（行政制本就拿影响力办事） |
| 历史模型 | 皇帝可以随便换 | 皇帝**付得起**才换得动 |
| 张力 | 消失 | 保留（皇权 vs 精英） |

`law_group_type` + `index` + `can_keep/can_pass` + `on_pass` + `modifier` + `pass_cost` + `ai_will_do`。

## 设计：三条互斥法令（同一 law_group_type，index 递增）

| 法令 | 教区继任行为 | modifier | pass_cost |
|---|---|---|---|
| **教省自主** index 0 | 完全原版，皇帝不介入 | 教士好感 +、影响力产出 − | 低 |
| **要职过问** index 1 | 都主教以上弹事件；普通教区按推举自动结算 | 中性 | 中 |
| **皇帝钦定** index 2 | 全部按钦定自动结算；仅普世牧首弹事件 | 教士好感 −、税/征召 + | 影响力（高） |

### 为什么这个方案更好

| | 硬编码分层 + 「记住上次选择」flag | 法令 |
|---|---|---|
| 记忆 | 要自建 variable 存储 | 法令本身就是状态 |
| 分层 | 硬编码在事件 trigger 里 | 由法令等级决定 |
| 玩家感知 | 一个 UI 开关 | 游戏内政策，有成本与权衡 |
| 史实性 | 弱 | 强（拜占庭教职政策确实反复摆动） |
| 与 `manor_reform_law` 同构 | 否 | **是** |

### 与 `request_realm_priest_replacement` 互动的分工

| 入口 | 时机 | 语义 |
|---|---|---|
| 互动 | 牧首**活着** | 主动更换（花影响力 / 虔诚） |
| 法令 + 事件 | 牧首**死亡** | 继任怎么办（由法令等级决定自动策略） |

**时机不重叠，不构成两个真相源。**
法令等级 0 时互动仍可用（教会自主 = 你得求他们）；等级 2 时互动近乎多余。

# 代价模型：两条独立的轴

**2026-11-09 追加。取代「固定影响力代价」。**

## 核心：控制成本 ≠ 接受成本

| 轴 | 问的是 | 驱动因素 | 支付形式 |
|---|---|---|---|
| **控制成本** | 能不能把他按上去 | 候选人的**能力 + 自身威望** | 影响力（皇帝掏） |
| **接受成本** | 教会服不服他 | 候选人的**品行 vs 教会价值观** | 全体教士好感 |

能力高/威望高的人：**按上去贵（不好摆布），但教会服气（反弹小）**。
恶名昭彰的人：**便宜（好收买），但教会炸锅**。

合成一个数会丢掉这个张力，所以必须分轴。

## 四类候选人

| 类型 | 影响力 | 教士好感 | 回报 | 原型 |
|---|---|---|---|---|
| **名望学者** | 高 | 低惩罚 | **皇帝合法性/虔诚 +**、教区繁荣 | 凯撒里亚的阿瑞塔 |
| 平庸之辈 | 低 | 中 | 几乎无 | 宫廷教士 |
| 恶名昭彰 | 低 | **高惩罚** | 政治可靠（忠诚） | 政治打手 |
| 政治重臣 | 中 | 中 | 影响力产出 + | 调任的老人 |

**无占优策略** —— 每类都有独特代价形态。

## 回报也分轴

   牧首威望 → 皇帝每月虔诚 / 合法性 +
   牧首能力 → 该教区税收 / 征召 / 发展度
   牧首品行 → 全体教士好感（持续）

史实依据：巴西尔一世复立印纳提俄斯，不只是换人，是**借有声望的牧首为自己盖章**。

# 校准修正：危机系统不能用在这个场景

**2026-11-09 追加。修正上一节的结论。**

## 上一节错在哪

上一节说「代价系统不用造，复用 investiture_crisis」。**这个结论对用量是错的。**

授职权之争的本质是**主权冲突**（教宗 vs 皇帝，两个竞争性主权者）。而拜占庭的牧首任命**从来不是主权问题**——皇帝在教会结构内部（symphonia），这是内政。

⇒ **干预人事 ≠ 干预教义。前者是行政，后者才是危机。**

## 史实：拜占庭真正的分裂不是因为「任命」

| 事件 | 触发点 |
|---|---|
| 佛提乌分裂 863-867 | 皇帝**罢免**印纳提俄斯，他仍有大批支持者 → **产生对立权威** |
| 阿森尼乌斯分裂 1261-1310s | 米海尔八世**罢免**阿森尼乌斯 → 追随者另立 |
| 圣像破坏 726-843 | **教义**分歧 |
| 里昂 / 佛罗伦萨合一 1274 / 1439 | **外部强加** |

共同点：不是「任命」，是「**罢免有威望的牧首 → 制造对立权威**」。
正常任命（巴西尔换印纳提俄斯等）**一次也没分裂过**。

## 结构问题：situation 是拉丁教会史，且全局唯一

```
@saeculum_obscurum_points    ← 娼妇政治（10c 罗马教廷）
@reform_phase_points         ← 克吕尼改革
@investiture_crisis_points   ← 格里高利七世 vs 亨利四世
@crusade_phase_points        ← 十字军
```

且 `is_unique = yes` ⇒ **全基督教共用一条时间线**。

⇒ 东正教的实际处境：西边推进度，自己被拖着走；自己做什么都推不动。
⇒ **不是玩家，是乘客。**

## 修正后的双层定价

| 行为 | 行政成本（我们管） | 危机催化剂（原版管） |
|---|---|---|
| **任命**（首选 / 推举 / 钦定） | 影响力 + 好感 | **不加** |
| 罢免平庸牧首 | 影响力 | 不加 |
| **罢免高威望牧首** | 影响力（大） | **加**（可能生成对立牧首） |
| 强推教义变更（圣像 / 合一） | — | **极高** |
| 顶着教规硬来（四婚） | 虔诚 | **加** |

### 判据

> **只在「挑战教义」或「制造对立权威」时碰危机系统。**
> **单纯行使人事权，只付行政代价。**

例：
- 利奥六世四婚 → **引发风暴**（挑战教规）
- 巴西尔换牧首 → **不引发**（内政）

同一个「干预教会」的动作，两种定价。这才是对的。

## 对实现的含义

1. 日常任命**不进** investiture_crisis —— 由我们的法令 + 事件 + 两轴定价体系承担
2. 只有「罢免高威望牧首」「强推教义/合一」「顶教规硬来」才上调催化剂
3. 若将来要做拜占庭自己的危机线，应**另建 situation**，而不是挤进拉丁时间线

- `investiture_crisis` 对东正教是否**实际可达**（西方催化剂可能让东正教永远推不动）
- 若不可达 ⇒ 更加说明「不该复用」

# 史实根据：这是能力问题，不是权力问题

**2026-11-09 追加。为双层定价提供历史依据。**

## 西方：教会就是唯一的文官系统

西罗马崩溃后识字阶层只剩教士。查理曼的宫廷文书、英格兰的财政、整个行政机器都寄生在教会身上。

国王往主教座塞人，塞进去的是不会读拉丁文、不会记账、不会处理产业纠纷的人。
**教会的反对是实质性的**：「你塞的人根本干不了这活。」

格雷戈里改革的核心诉求之一正是「让受过教育的人担任圣职」。
⇒ 授职权之争在西方**真的有两面**：

| 方 | 诉求 | 是否成立 |
|---|---|---|
| 教宗 | 你的人不会管事 | **成立** |
| 皇帝 | 我需要忠诚的人在唯一能管事的岗位上 | 也成立 |

两边都有道理，所以才是真危机。

## 东方：文官系统是平行的

拜占庭保留完整世俗知识精英：君士坦丁堡大学（425）、书记官 notarios、
法官 krites、税务官 logothetes、流官轮转。

皇帝手上本来就有一批受训政务官 ⇒ 教会的「你不识字」论点**不成立**。
⇒ 东部的冲突**只剩法理层面**：谁有权，不涉及干不干得好。

## 机械对应

| | 西方 | 东方 |
|---|---|---|
| 教会反对的实质 | 你会毁了这个教区 | 权力分配 |
| 任命后的功能后果 | 治理变差 | 治理不变 |
| 代价形态 | 功能惩罚 + 政治代价 | **纯政治代价** |
| 危机级别 | 高 | 低 |

```paradox
# 皇帝钦定后的教区效果
if = {
    limit = { NOT = { government_has_flag = government_has_merit } }
    add_title_modifier = { modifier = see_mismanaged }   # 没有流官体系 → 治理下降
}
# 有 merit 体系 → 无功能惩罚，只付政治代价
```

`government_has_merit` **1.20 已存在**（见 `councillor_court_chaplain` 的显示名分支），
即「行政制/天朝制 = 有流官体系」的机制标记。无需新造概念。

## 一般化

> **一个制度的抗干预能力，取决于「离开它之后还有没有人会干活」。**

西方离不开教会 ⇒ 教会能谈判。
东方有平行系统 ⇒ 皇帝可以直接换人。

推广：任何「专业垄断 + 缺乏替代供给」的领域，其从业者都会获得
超出正式权力的议价能力。

## 附：诺曼贵族识字率 —— 教会 = 唯一的 I/O 层

- 征服者威廉**本人不识字**，章程上画十字，不是签名
- 贵族普遍用**蜡封**代替签名，因为签不了
- 《末日审判书》（1086）由教士书记员完成；下令者读不了它
- 英格兰中书省直到 14 世纪仍是教士地盘
- 《大宪章》（1215）是**盖印**的，不是签字的

**语言学铁证**：英语 `clerk`（书记员）= `cleric`（教士），同一个词。
连现代英语里 `clerk`（法院书记官 / 议会秘书）都仍是这层意思。

⇒ 西方教会不只是机构，是**唯一的 I/O 层**：记账、文书、档案、通信全在教士手里。
⇒ 国王往主教座塞亲信 = 往系统管理员位置塞一个没见过键盘的人。
⇒ 教会的反对不是争权，是**「你要让系统停摆」——而且它说得对。**

## 一般化：缺失的机制会长出替代协议

| 缺失的机制 | 被迫的替代 | 制度化后果 |
|---|---|---|
| 贵族不会写字 | **蜡封** | 封印成为权威象征（教皇诏书用铅封至今） |
| 引擎没有依赖声明 | **兼容补丁** | 补丁作者成为生态分工 |
| 本地化按字节长度定胜负 | **`replace/`** | 汉化组必须整份接管 |
| 引擎不记录覆盖双方的值 | **人肉 diff** | 本次排查全在做这个 |

**蜡封就是中世纪的兼容补丁。**

## 对双层定价的最终确认

> 西方教会能说「不」，不是因为它有权，是因为**它是唯一会干活的人**。
> 东方皇帝能说「我说了算」，不是因为他权大，是因为**他有替代的人**。

⇒ `the_christian_church` 的授职权之争在西方是**真危机**（威胁行政机器运转）；
   拜占庭塞人最坏只是「换了个你不喜欢的牧首」，不是「国家无法记账」。
⇒ 同一个动作：一个是系统风险，一个是人事变动。

# 时代的量化：用文化时代当「教会垄断度」的代理

**2026-11-09 追加。把史实论证落成可计算的乘数。**

## 时代乘数

| 时代 | 乘数 | 史实：识字能力在哪 |
|---|---|---|
| `culture_era_tribal` | **×2.0** | 无文字官僚，教会（若有）即全部书写能力 |
| `culture_era_early_medieval` | **×1.5** | 修道院学校 + 教会书记 |
| `culture_era_high_medieval` | **×1.0** | 大学出现（博洛尼亚 1088 / 巴黎 / 牛津），世俗识字层萌芽 |
| `culture_era_late_medieval` | **×0.6** | 世俗法学家、公证人、宫廷官员成规模 |

二次修正（已核实的创新点名）：
- `innovation_court_officials`（宫廷官员，晚期）→ **×0.5**
- `innovation_baliffs`（郡守，早期）→ ×0.85

## 学识的双重符号（本模型最漂亮处）

| 谁的学识 | 影响 | 方向 |
|---|---|---|
| **皇帝的学识** | 懂不懂教会法、会不会玩人事博弈 | **降低**控制成本 |
| **候选人的学识** | 好不好摆布 | **提高**控制成本，同时**提高**回报 |

> 博学的皇帝**更容易**把强人按上去；博学的候选人**更难**被按上去。

## 完整公式

```paradox
imposition_influence_cost = {
    value = 50
    multiply = era_multiplier
    if = { limit = { has_innovation = innovation_court_officials } multiply = 0.5 }
    if = { limit = { has_innovation = innovation_baliffs }        multiply = 0.85 }

    subtract = { value = learning  multiply = 2 }                    # 皇帝懂行 → 便宜
    add = { value = scope:candidate.learning  multiply = 2 }         # 候选人有本事 → 贵
    add = { value = scope:candidate.prestige  divide = 100 }         # 候选人有威望 → 贵
}

clergy_opinion_penalty = {
    value = 15
    multiply = era_multiplier
    if = { limit = { has_innovation = innovation_court_officials } multiply = 0.6 }
    # + 品行修正（见代价模型一节）
}
```

## 为什么这套公式成立

它其实在量化**「教会垄断程度」**：

| 时代 | 教会垄断度 | 塞人的功能风险 |
|---|---|---|
| 部落 | ~100% | 教区停摆 |
| 早期 | ~90% | 治理明显下降 |
| 盛期 | ~60% | 有替代者但不够 |
| 晚期 | ~30% | 教会只是众多机构之一 |

⇒ `the_christian_church` 的授职权之争爆发于 11-12 世纪，
   恰好是垄断度从 ~90% 掉到 ~60% 的窗口（旧结构瓦解、新结构未成型）。
⇒ P 社把这个窗口做成了危机阶段；我们让成本随时代滑落，就能复现同一条曲线。

## 待定数值

以上乘数为设计初值，需与本体经济数值对齐（影响力获得速率、pass_cost 量级）。
等 DLC 后按实际数值标定。

# 特判：制度发育 ≠ 游戏时代

**2026-11-09 追加。修正时代乘数在「有文官传统」文化上的失真。**

## mod 已经处理了一半

`common/on_action/lamps_on_game_start_actions.txt` 里已把七支文化提到早期中世纪：

```
culture:greek  culture:han  culture:persian  culture:parthian
culture:levantine  culture:egyptian  culture:ce_copt
```

但早期中世纪乘数 = ×1.5，对「从未中断的文官系统」仍然偏高。

## 修正：跳过时代乘数

```paradox
# 有文官传统的文化：制度发育度不受游戏时代限制
if = {

}
```

同一份名单已经存在于 `on_action` 的 `join_era` 段。**不能在设计里再抄一份**
（即本次排查反复遇到的「两个真相源」）。

正确做法：抽成 scripted trigger，两处引用——

suiginton_has_bureaucratic_tradition_trigger = {

- 定价：`if = { limit = { ... trigger } multiply = 0.667 }`

# 第三轴：双向好感与「强强联合」

**2026-11-09 追加。修正「能力溢价」的含义。**

## 核心：成本的真来源是「意志分歧」，不是「能力」

一个博学的候选人之所以贵，不是因为强，而是因为**他的意志与皇帝不同**。
若一致，强不是负担，是资产。

⇒ 能力溢价必须乘以「分歧度」。

```paradox
一致性 = min( 皇帝对候选人的好感, 候选人对皇帝的好感 )
# 取 min 是对的：联盟需双方同意，单向好感不是联盟

控制成本 = (base × 时代乘数)
         − 皇帝的学识
         + 候选人(学识 × 2 + 威望 / 100) × (1 − 一致性 / 100)
```

好感触发器写法（已核实，`00_adoption.txt:335`）：

```paradox
opinion = {
    value >= 25
    target = scope:candidate
}
```

## 四格与史实对照

| 组合 | 控制成本 | 结果 | 史实 |
|---|---|---|---|
| **强者 + 双向好感高** | **低** | **强强联合**：合法性 + 治理双收益 | **巴西尔一世 × 佛提乌**（867 前） |
| **强者 + 一方敌视** | **极高** | 按上去也是隐患 | **利奥六世 × 阿瑞塔斯**（反对四婚） |
| 庸者 + 好感 | 低 | 稳定但平庸 | 多数情况 |
| 庸者 + 敌视 | 中 | 压抑的怨恨 | — |

两个史实分别落在两个极端格，同朝代同制度 ⇒ 模型抓住了真实变量。

## 强强联合的收益（双向）

```paradox
# 皇帝侧
add_character_modifier = { modifier = byz_strong_alliance_emperor }   # +合法性 / +虔诚 / +影响力
# 牧首侧
add_character_modifier = { modifier = byz_strong_alliance_patriarch } # 教区产出+ / 教会声望+
```

两个有能力且互信的人 ⇒ 不只是成本减免，是**额外治理收益**。

## ⚠️ 联盟是有条件的，而且会碎

史实：巴西尔一世 × 佛提乌的联盟在 867 年破裂——
教皇尼古拉一世施压 + 印纳提俄斯派反扑 ⇒ 巴西尔废佛提乌、复立印纳提俄斯。

> **联盟越强，破裂代价越大。瓦解时，最强的牧首变成最强的对手。**

条件（任一跌破则翻转）：

```paradox
NOT = {
    OR = {
        clergy_opinion < -20
        legitimacy_level <= 2
        # 或外部压力（教皇 / 反教宗介入）
    }
}
```

翻转 → `byz_patriarch_alienated` → 牧首成为 claimant / rival。

**且无法撤销已给出的收益** —— 这正是历史上最难看的一幕：
你亲手扶上去的强人，成了你最棘手的敌人。

## 与其它选项的关系

强强联合 = 高收益 / 高风险；折中人选 = 低风险 / 低收益。
形成标准风险梯度，四类候选人都无占优策略。

# 第四维：牵制（hook）—— 意愿与强制力分离

**2026-11-09 追加。好感 = 意愿；牵制 = 强制力。两者不可混为一谈。**

## 1.20 的牵制类型（实测）

```
favor_hook / strong_favor_hook              人情
weak_blackmail_hook / strong_blackmail_hook 把柄（黑料）
obligation_hook / indebted_hook             义务 / 债务
loyalty_hook / supporter_hook               忠诚 / 支持者（正向）
deposed_antipope_hook                       被废反教宗的牵制 ★
```

触发器：`has_hook_of_type` / `has_usable_hook` / `has_strong_hook` / `time_to_hook_expiry`

## 关系四态

| 态 | 判据 | 控制成本 | **协同** |
|---|---|---|---|
| **联盟** | 双向好感高 **且** 无胁迫牵制 | 低 | **有** |
| **胁迫** | 皇帝持 blackmail hook | 低 | **无** |
| **人情** | 皇帝持 favor hook | 中低 | 无（用完即失） |
| **受制** | **牧首持皇帝的牵制** | **极高** | 无（且危险） |

## 核心判据

> **胁迫能买到服从，买不到协同。**

协同需要自愿。⇒ 牵制只作用于**成本**，不作用于**一致性**。

```paradox
一致性 = min(皇帝→候选人 好感, 候选人→皇帝 好感)   # 只由好感决定

强制系数 = 1.0
# strong blackmail → 0.4；weak blackmail → 0.7；favor → 0.85
# 反向（他持你的可用牵制）→ 1.8

控制成本 = (base × era − 皇帝学识
           + 能力溢价 × (1 − 一致性/100)) × 强制系数

# 协同只在联盟态
if = { limit = { 一致性 >= 50  AND  NOT = { 持 blackmail hook } }
       apply_modifier = byz_strong_alliance }
```

## 把柄的三条反噬

1. **他记恨**：胁迫就位的牧首带 opinion 惩罚
2. **有有效期**：`time_to_hook_expiry` —— 过期那天关系比之前更差（已经用过了）
3. **反向性**（最狠）：`deposed_antipope_hook` 说明**引擎已把「废掉教职持有者」的后果做成牵制**

⇒ 我们前面在危机层设计的「罢免高威望牧首 → 制造对立权威」，机制已存在：

```
强行按人 → 教会不满 → 旧牧首成对立权威
                        ↓
               他持 deposed_antipope_hook on 你
                        ↓
               可反过来要挟
```

**不用造这个后果，只要不屏蔽它。**

## 三种权力来源

| 来源 | 机制 | 消耗 | 怨恨 | 后续 |
|---|---|---|---|---|
| **好感** | opinion | 无 | 无 | 可增长 |
| **人情** | favor_hook | **一次性** | 无 | 关系不变 |
| **把柄** | blackmail_hook | 保留至过期 | **有** | **更差** |

> 人情是借来的权力，把柄是勒索来的权力，好感是长出来的权力。

三种代价曲线，正好覆盖 CK3 的核心张力。

# 玩家侧修正：不模拟玩家自己的意愿

**2026-11-09 追加。修掉一致性的输入源。**

## 问题

CK3 的 `opinion` 有方向性：

- **候选人对皇帝的好感** → 玩家可见（角色界面）
- **皇帝对候选人的好感** → **纯模拟产物**，算了但从不使用

因为玩家想怎么看他，只有玩家知道。
用它决定成本 = **用玩家无法感知的隐藏值约束玩家决策** = 拿掉主体性。

⚠️ CK3 在别处一直是对的（选宿敌 / 是否宽恕 / 选生活方式），都是让玩家自己宣示。

## 修正

| 输入 | 来源 | 可用性 |
|---|---|---|
| ~~皇帝对候选人的好感~~ | 隐藏模拟产物 | ❌ |
| **候选人对皇帝的好感** | 角色界面可见 | ✅ |
| **玩家宣示的立场** | 事件选项 | ✅ |

```paradox
一致性 = min( 候选人对皇帝的好感, 玩家宣示信任度 )
```

## 事件选项因此有了真实分量

| 选项 | 效果 |
|---|---|
| **「我信他」** | 一致性 = 候选人对你的好感 → 可能触发**强强联合**（低成本 + 协同） |
| **「我得留个心眼」** | 一致性 = 0（无协同），**开启「找把柄」路径** → 后续可获 `blackmail_hook` |

```
宣示戒备 → 派人盯着 → 找到把柄 → 可胁迫
                              ↓
                    但胁迫买不到协同（第四维判据）
```

⇒ 玩家主动选择了一条更短视但更可控的路。两条路都合理，代价形态不同。

## AI / 玩家分流

```paradox
if = { limit = { is_ai = yes }
       一致性 = min(皇帝→候选人, 候选人→皇帝)     # AI 用完整公式
}
else = {
       一致性 = min(候选人→皇帝, 玩家宣示值)      # 玩家用可见事实 + 宣示
}
```

同一机制、不同输入路径。不是特殊对待，是**主体不同**：一个有主体性，一个没有。

## 原则

> **不要把玩家拥有权威的东西交给系统去模拟。**

玩家的意愿是玩家独占的权威；系统的职责是模拟**玩家的意愿所面对的世界**
（对方怎么反应、后果是什么）。

与「干预人事 ≠ 干预教义」同构：
前者拆开**两种冲突**，后者拆开**两种主体**。

# 第五维：军事威望（只对冲一项）

**2026-11-09 追加。罗马政治里「一俊遮百丑」的机制化。**

## 可用指标（实测）

- `prestige_level`（威望等级）—— CK3 里威望本就靠功业累积，即战功的量化形态
- `legitimacy_level`（合法性等级）
- 引擎**没有** `battle_wins` / `wars_won` 这类触发器

## 只对冲「控制成本」

| 代价项 | 军事威望能对冲吗 |
|---|---|
| **控制成本**（能不能把人按上去） | ✅ **能** |
| **接受成本**（教会服不服他） | ❌ **不能** |
| **教义冲突**（圣像破坏 / 强行合一） | ❌ **完全无效** |

> **军队能让人闭嘴，不能让人服气。**

## 识字是门槛，不是线性项

```paradox
军事修正 = 1.0
if = { limit = { prestige_level >= 3 } subtract = 0.25 }
if = { limit = { prestige_level >= 4 } subtract = 0.10 }
if = { limit = { prestige_level >= 5 } subtract = 0.10 }

# 大字不识一个 → 军事威望只生效三分之一
if = { limit = { learning < 6 }
       军事修正 = 1.0 - (1.0 - 军事修正) / 3
}
```

**为什么不归零**：文盲将军皇帝仍能**威慑**，只是无法**说服**。
⇒ 威慑与说服是两种不同的权力，军事威望只买到前者。

## 尼基弗鲁斯二世：模型自动算出的死法

军事威望满格：961 收复克里特、965 收复奇里乞亚与安条克。

| 项 | 他的值 |
|---|---|
| 控制成本 | **极低**（确实想按谁按谁） |
| 接受成本 | **爆表**（禁教会积累地产 + 严苛道德立法 + 苦修作风） |
| 一致性 | **全员为负** |

⇒ 969 年被皇后赛奥法诺与约翰·齐米斯基斯刺死于卧室。

> **他买到了「能按人上去」，没买到「教会服气」。**

模型自然复现该结局，因为我们一开始就把两种成本拆开了。
**这不是巧合，是拆对了的证据。**

## 与教义冲突的边界

```
按人上去  → 军事威望可压价
改教义    → 军事威望归零，直接进危机系统（investiture_crisis 或另建）
```

两条路、两种世界。军事威望只在第一条上有效。

## 完整公式（五维汇总）

```paradox
一致性 = min(候选人对皇帝好感, 玩家宣示信任度)    # 玩家
       = min(皇帝→候选人, 候选人→皇帝)            # AI

控制成本 = (base × 时代乘数 − 皇帝学识
           + 能力溢价 × (1 − 一致性/100))
           × 强制系数（牵制）
           × 军事修正（威望 × 识字门槛）

接受成本 = base × 时代乘数 × 品行修正        # 军事威望无效

持续风险 = 联盟态是否维持 → 跌破则翻转为 claimant/rival
```

# 第六维：世界状态 —— 教会权威系数

**2026-11-09 追加。前五维都是人物属性，这一维引入世界状态。**

## 关键史实：圣像破坏的时机

| 时间 | 事件 |
|---|---|
| 7 世纪 | 连续丢失叙利亚、埃及、北非（半个帝国） |
| **717–718** | **阿拉伯人围困君士坦丁堡——最接近陷落的一次** |
| **726** | **利奥三世颁布第一道禁圣像敕令** |
| 741–775 | 君士坦丁五世强力推行（754 海尔利亚会议） |
| 787 | 伊琳娜复圣像（第二次尼西亚会议） |
| 815 | 利奥五世再禁 |
| 843 | 赛奥多拉复圣像（正教凯旋） |

**717 到 726 只隔 8 年。**

全民都在问：「我们被神抛弃了吗？是不是因为拜偶像？」
⇒ **圣像破坏不是皇帝强推，是整个社会在怀疑自己信的教义。**

## 机制：教会权威系数

> **教会刚被打败，它就没资格说「我们的教义是对的」。**

```paradox
教会权威系数 = 1.0
# 崩塌（丢失圣地 / 首都曾被围 / 大瘟疫）→ × 0.6
# 鼎盛（收复圣地 / 大胜）               → × 1.4

接受成本 = base × 时代乘数 × 品行修正 × 教会权威系数
```

**注意区分两种机制**：

| 机制 | 方向 | 效果 |
|---|---|---|
| 军事威望（第五维） | 皇帝**更有力** | 强制（压控制成本） |
| 教会权威崩塌（本维） | 教会**更无力** | 说服力消失（降接受成本） |

一个在加，一个在减。**圣像破坏是后者起的作用。**

## 解释了「为什么是 726 年」

| 时期 | 教会权威 | 改教义成本 |
|---|---|---|
| 650 | 高（丢地但教义未受质疑） | 高 |
| **726** | **崩塌** | **低** |
| 787 | 恢复 | 反过来，**复圣像变便宜** |
| 843 | 高 | 复圣像定案 |

⇒ **教义改动的成本取决于「现教义的信誉」，而信誉由战报决定。**

## 附带：接受成本需分两层

1439 佛罗伦萨合一：精英签字、民众暴动、教会分裂。

| 层 | 接受成本 | 原因 |
|---|---|---|
| 精英 | 低 | 快亡国了 |
| **民众** | **爆表** | 拉丁人是异端（1204 创伤） |

⇒ 教义变更的接受成本应分 **精英 / 民众** 两层。
⇒ 1204 后的合一 = 唯一一次民众层完全拒绝的教义变更（不是神学问题，是民族创伤）。

## 模型的形态变化

```
人物属性（谁当皇帝、谁当牧首）
    ×
世界状态（教会还有没有信誉、帝国还在不在赢）
    =
最终成本
```

同一对君臣，在 726 年和 787 年要付完全不同的代价。
⇒ 历史不由人物属性单独决定。

## 六维汇总

| # | 维度 | 影响 | 类型 |
|---|---|---|---|
| 1 | 时代/制度 | 控制 + 接受 | 世界（静态） |
| 2 | 品行 | 接受 | 人物 |
| 3 | 双向好感 | 分歧 → 控制 | 关系 |
| 4 | 牵制 | 强制力 → 控制 | 关系 |
| 5 | 军事威望 | 控制（受识字门槛调节） | 人物 |
| 6 | **教会权威** | **接受** | **世界（动态）** |

# 更正：教会权威系数不能绝对化（第七次自我更正）

**2026-11-09 追加。修正第六维的错误分支。**

## 错在哪

原写法：

```paradox
# ❌ 错的
if = { 近期收复圣地 / 大胜 → 教会权威系数 multiply = 1.4 }
```

**把「教会的威望」与「皇帝的胜利」混成一个系数。**

但打下耶路撒冷是**皇帝的**权威，不是教会的权威。
且按当时逻辑，**胜利本身就是神学证明**：你赢了 ⇒ 神站你这边 ⇒ 你信的这套是对的。
⇒ 一个打赢了的破坏圣像派皇帝，在神学上就是对的，教会没有反证。

## 修正：否决权是相对值

```paradox
# ✅ 对的
教会否决权 = 教会权威 / 皇帝权威
接受成本 = base × 时代乘数 × 品行修正 × 教会否决权
```

| 情况 | 教会 | 皇帝 | 否决权 |
|---|---|---|---|
| 皇帝大胜、教会平庸 | 1.0 | 2.0 | **0.5** → 改教义便宜 |
| 教会主导收复圣地 | 1.8 | 1.0 | **1.8** → 改教义昂贵 |
| 双弱（常态） | 1.0 | 1.0 | 1.0 |

**教会权威只能从教会自己的来源增长**：圣迹、教会主导的收复、教产与修道院兴盛。
**绝不会因为皇帝打赢而增长。**

## 由此：第五维与第六维是同一个比值的两端

| 维 | 作用 | 含义 |
|---|---|---|
| 军事威望（第五维） | **分母↑**（皇帝权威） | 你按得动 |
| 教会权威（第六维） | **分子↑**（教会权威） | 他们拦得住 |

此前当作两个独立系数，实际是一个分数的上下两半。

## 反例与限制

君士坦丁五世军事成功（对保加利亚、阿拉伯皆胜），圣像破坏仍在 787 年被伊琳娜推翻。
原因不是「教会赢了」，而是**伊琳娜需要修道院支持以巩固摄政地位**——王朝政治，非神学辩论。

⇒ **军事胜利能压低教义变更的阻力，但不能永久锁死结论。**
⇒ 军事光环消退后（后继者无能，或掌权者需要别的支持者），旧账会被重算。

**实证**：815 年利奥五世再禁圣像——因 811 年对保加利亚惨败（尼基弗鲁斯一世战死），
「拜偶像招致神罚」的说法重新有了市场。

⇒ 同一条曲线来回跑了两百年（726 禁 → 787 复 → 815 禁 → 843 复）。

# 原则补强：前提可约束玩家，结果不该约束玩家

**2026-11-09 追加。为「不模拟玩家意愿」提供可操作的判据。**

## 引擎其实给了正确的工具

EU4 的 `00_diplomatic_actions.txt` 里，态度门槛写作：

```paradox
NOT = {
    ai_attitude = {
        who = FROM
        attitude = attitude_hostile
    }
}
```

`attitude`（通用）与 **`ai_attitude`（只对 AI 生效）** 是两个不同触发器。
外交互动用后者 —— **明确只限制 AI，不限制玩家**。

CK3 的等价物：`is_ai = yes`。

⇒ 反模式不是架构缺陷，是**忘记用引擎已提供的区分**。

## 判据：前提 vs 结果

| 类别 | 例子 | 能当门槛？ |
|---|---|---|
| **前提**（选角色时即接受） | 怯懦 → 不能选勇武选项 | ✅ |
| **客观状态** | 有停战 → 不能宣战 | ✅ |
| **结果**（模拟的记账） | 你对他的好感 / 你的态度 | ❌ |

- 「怯懦不能勇武」是对的：那是角色前提，使角色有性格
- 「你对他好感低所以不能结盟」是错的：好感是系统记账，属结果
  ⇒ **让记账变成笼子**

## 门槛 vs 价格

| | 门槛 gate | 价格 price |
|---|---|---|
| 语义 | 世界不允许 | 世界允许，但要付钱 |
| 玩家感受 | 被剥夺 | 有选择 |
| 适用 | 物理/类别不可能 | 其余一切 |

**玩家意愿与世界阻力相遇时，首选价格。**

本设计即一次系统性的 **gate → price** 转换：

| 原版 | 本设计 |
|---|---|
| `piety_level >= 3` | 影响力 + 好感（价格） |
| 教区继任系统定 | 法令分级，玩家选 |
| 一致性由隐藏值定 | 玩家宣示立场 |

> 原版的错是用**门槛**表达阻力；正确的是用**价格**表达阻力。

# 拉丁敌视：把静态惩罚改成记账

**2026-11-09 追加。民众层接受成本从乘数改成存量。**

## 原则

> **修正符是结论，记账是过程。**

修正符说「你现在 +10% 成本」；记账说「你欠着 30 点，而且还在涨」。

## 三条规则

```
拉丁敌视 latin_enmity   0 …

积累
  拉丁十字军讨伐           +10
  首都 / 圣地被拉丁攻陷     +25
  被强加合一               +15
  公开拒绝罗马使者          +2

衰减
  每 10 年 −1              ← 几乎不衰减，民族创伤不会忘

花费（花掉不减存量！）
  「斥拉丁人为异端」        → 一次性合法性 + 民众支持
```

**核心规则：花掉不减少存量。**
民意不会因为你用了它就消失；每用一次都是一次公开的反拉丁表态。

## 于是它既是资产也是债务

| 表面 | 实际 |
|---|---|
| 60 点敌视可换合法性 | ✅ 真能换 |
| 存量不降 | 你只是在**借** |
| 未来与罗马妥协 | 成本 × (1 + 累计公开表态次数 / 5) |

**越用越好用；越好用越用。代价是：孙子永远签不成合一。**

## 史实链条

| 年 | 事件 | 记账 |
|---|---|---|
| 1204 | 第四次十字军洗劫君士坦丁堡 | **+50**（起点爆表） |
| 1261 | 米海尔八世收复首都 | 存量不动 |
| 1274 | 里昂合一 | 精英签、**民众暴动**、教会分裂 |
| 1439 | 佛罗伦萨合一 | 精英又签、**民众拒绝执行** |
| 1453 | 城破 | 「宁见土耳其头巾，不见拉丁主教冠」※ |

※ 据传出自卢卡斯·诺塔拉斯，**大概率是后人附会**，但准确表达了当时的氛围。

⇒ 250 年、三次合一、一次没成。原因同一个：1204 那笔账从未清掉，每次强推都在往上加。

## 意义：从隐藏惩罚变成可管理存量

| | 乘数（原） | 记账（新） |
|---|---|---|
| 玩家可见 | ❌ | ✅ |
| 玩家可影响 | ❌ | ✅（政策/事件/外交） |
| 玩家要付代价 | 不知道 | ✅（每次花费透支未来） |

⇒ 又一次应用那条原则：**中间产物应该可协商。**
原来它是结论（民众不接受），现在它是过程（在管理一个存量）。

## 实现

```paradox
change_variable = { name = latin_enmity  add = 25 }   # 1204 洗劫

民众接受成本 = base
             × (1 + latin_enmity / 50)
             × (1 + public_commitments / 5)
```

两个变量：`latin_enmity`（存量）、`public_commitments`（计数）。
一个表达「有多恨」，一个表达「公开表态过几次、还有多少脸面可退」。

# 拉丁敌视的完整形态：安德洛尼卡一世案例

**2026-11-09 追加。为「花费」补齐三种后果与刹车机制。**

## 背景：1182 年

曼努埃尔一世 1180 年死，留 11 岁阿莱克修斯二世 + **拉丁出身的摄政太后**（安条克的玛丽亚）。
君士坦丁堡的拉丁商人（比萨/热那亚/威尼斯）享商业特权，民怨已沸。

安德洛尼卡从流亡地归来，**唯一的政治资本就是把民怨兑现**。

1182 年拉丁人大屠杀：拉丁区被焚，拉丁居民被杀
（中世纪史料称六万，现代估计低得多，**数字争议很大**）。
1183 年绞死阿莱克修斯二世，娶原许配给那孩子的 12 岁法国公主阿格妮丝。

## 花费产生两笔新账

| 新账 | 内容 | 到期 |
|---|---|---|
| `latin_hostility` | 拉丁人记账：他们恨你 | **1204（22 年后）** |
| `mob_dependency` | 合法性建立在持续煽动上 | **1185（3 年后）** |

**1182 → 1204**：第四次十字军洗劫君士坦丁堡，1182 年屠杀是其公开旧账之一。
⇒ 「花掉不减存量」的真正含义：不但不减，**还生了一个对面的存量**。

**1185**：诺曼人入侵，第二大城市塞萨洛尼基被攻陷。
9 月伊萨克二世在圣索菲亚被拥立，安德洛尼卡出逃被抓，
**在赛马场被暴民拷打致死**（吊脚、剥皮、断肢）。

⇒ **他死在赖以起家的那个力量手里。**

## 正反馈螺旋

```
民众恨拉丁人 → 政客兑现 → 掌权
                 ↓
        拉丁人恨你 → 来报复
                 ↓
        民众更恨拉丁人 → 能兑现更多
                 ↓
              … 直到 1204
```

**螺旋必须有刹车，否则游戏自我毁灭。**

刹车 = 精英层：贵族与商人靠拉丁贸易/雇佣兵吃饭，牧首不愿基督徒杀基督徒。
安德洛尼卡上台第一件事是**清洗贵族** —— **拆掉刹车，然后被自己踩下的油门撞死。**

## 变量设计

```paradox
latin_enmity       # 存量：民众恨拉丁人（可花，花掉不减）
latin_hostility    # 对面账：拉丁人恨你
mob_dependency     # 副作用：合法性依赖持续煽动
elite_resistance   # 刹车：精英还剩多少能力阻止
```

花一次 `latin_enmity`：

```
latin_hostility += 10            # 对面记一笔，未来更狠
mob_dependency  += 15            # 合法性更依赖它
elite_resistance -= (清洗贵族才能继续花)
```

当 `mob_dependency` 高 + 发生军事失败 → **反噬**：暴民转向，废黜。

## 设计原则

> **你能花掉的资源，正是会杀了你的力量。**

比「资源有代价」更狠：**因为是同一样东西**。
不是你花了钱会破产，而是你花掉的**民愤本身**会在某天转头吃你。

# 花费 = 抵押承诺，到期要还

**2026-11-09 追加。修正「花费」的性质：不是消耗资源，是抵押信用。**

## 核心

喊「我能收拾他们」= 把民愤兑换成**一个承诺**。承诺有到期日（拉丁人真的来时）。

| 到期时 | 结果 |
|---|---|
| **真有本事**（舰队开进威尼斯 / 罗马） | **兑现** → 合法性暴涨，对面账被压住 |
| **没本事**（安德洛尼卡） | **违约** → `mob_dependency` 反噬 |

```paradox
承诺     = 花掉的 latin_enmity 数量
偿付能力 = f(军事力量, 威望等级, 近期胜绩)

到期事件（拉丁报复 / 危机）:
  if 偿付能力 >= 承诺 → 兑现
  else                → 违约
```

## 与第五维的接口

| 用途 | 作用 |
|---|---|
| 军事威望（第五维） | **压低控制成本**（你按得动） |
| 军事威望（本维） | **偿付能力**（你还得起） |

**同一个武力，两种用途：压价 和 还债。**

## 安德洛尼卡的账

| 项 | 值 |
|---|---|
| 承诺 | **极高**（煽动全国，血洗拉丁区） |
| 偿付能力 | **极低**（1185 连第二大城市都保不住） |
| 结果 | 违约 → 赛马场被撕碎 |

**他喊得最响的那句话，是他唯一还不起的债。**

## 兑现成功要给奖励，不只是免罚

> 「我早说了我能收拾他们，看，我做到了」——最强的合法性来源，比加冕都硬。

```paradox
add_legitimacy = 大量
add_prestige = 大量
reduce latin_hostility       # 对面老实了
reduce mob_dependency        # ★ 民众满意，不再需要持续喂养
```

**★ 是关键**：兑现成功**降低** `mob_dependency` ——
因为你不再靠煽动维持统治，你证明了你不只会喊。

这也是安德洛尼卡缺的出口：他若打赢诺曼人，
就从「煽动者」变成「保卫者」，账就清了。
**他输的不是道德，是塞萨洛尼基。**

## 完整三角

| 选择 | 风险 | 收益 |
|---|---|---|
| **不花** | 无 | 无（激进派不满） |
| **花了且兑现** | 需要真本事 | **合法性暴涨 + 民愤清算** |
| **花了但违约** | 身死国灭 | 无 |

三角完整，无占优策略。
且在 1180 年代的拜占庭，第二项赔率低到几乎不可能 —— **这才是历史上它没发生的原因。**

# 对照案例：巴西尔二世 —— 同样的强硬，不同的结局

**2026-11-09 追加。为「残酷是否有效」提供正向对照。**

## 逐项对照

| 维度 | 巴西尔二世 | 安德洛尼卡一世 |
|---|---|---|
| 偿付能力 | 极高（1014 克莱迪翁后保加利亚再未恢复） | 极低（保不住塞萨洛尼基） |
| 支撑结构 | 职业军 tagmata + 官僚 + 个人能力 | **只有暴民** |
| 残酷性质 | **工具性**（挖眼为终结战争） | **表现性**（维持煽动） |
| 代价谁付 | 保加利亚战俘（敌人） | 首都拉丁居民（居民） |
| 结果 | 1018 保加利亚并入，巴尔干安定一世纪 | 三年身死国乱 |

## 关键：拆刹车后还有没有方向盘

两人都清洗贵族，但：

- 巴西尔二世有职业军 + 官僚治理，贵族是障碍不是支柱 ⇒ 拆了没事
- 安德洛尼卡只有暴民，贵族是唯一治理结构 ⇒ 拆了就没了

> **权力可以绕过任何一个群体，前提是你有另一个群体撑着。**

⇒ 巴西尔二世是「东方皇帝能说我说了算，因为有替代的人」的完美实现；
   安德洛尼卡是它失效时的样子。

## 工具性残酷 vs 表现性残酷

```
工具性：目标明确 → 手段有效 → 达到即停止
表现性：为了展示 → 需不断升级 → 边际效用递减
```

巴西尔挖 15000 人眼睛后**收手**（战争结束了）。
安德洛尼卡**不能收手**（权力来源就是持续愤怒）。

> **表现性残酷会上瘾，因为它需要不断升级才能维持效果。**

```paradox
# 工具性：一次性，目标达成后依赖下降
if = { 敌人已屈服 → mob_dependency -= 20 }

# 表现性：每次都要升级（耐受性）
每次花费 → mob_dependency += 15
         → 下次所需量 × 1.2
```

## 巴西尔二世的失败：不可继承

他未婚无嗣，建立的是**全靠个人能力**的秩序。
死后君士坦丁八世无能 → 贵族反扑、官僚膨胀 → 一个世纪慢性衰退。

> **一个全都依赖你本人的统治，必然在你的继承人身上崩塌。**
> **他不是没解决问题，是把问题推迟了一代人。**

CK3 机制天然可表达：继承、能力、派系，全是现成的。

## 本维最终形态

| 项 | 变量 |
|---|---|
| 残酷是否有效 | `偿付能力 >= 承诺` |
| 拆刹车是否安全 | 有无替代支撑（职业军 / 官僚 = `government_has_merit`） |
| 会不会上瘾 | 工具性 vs 表现性 |
| 能不能传下去 | **继承人能力** ← CK3 的核心，强势皇帝的共同死法 |

# 死账机制：决定收账的是债主的实力

**2026-11-09 追加。修正「到期检查」为「持续检查」。**

## EU4 的现成对照

```
侵略扩张点数 AE   = 记账存量
包围网成立        = 到期事件
他们敢不敢动手     = 偿付能力检查
```

「吃包围网是包围网，但不敢对你动手」= **账到期了，但债主太弱，收不了账**。

## 修正：看债主实力，不只是你的偿付能力

```
债主实力 > 你 → 来收账 → 违约 → 反噬
债主实力 < 你 → 不敢来 → 变「死账」，**但不消失**
```

## 1204 年是教科书案例

| 年 | 事件 |
|---|---|
| 1182 | 安德洛尼卡花账 |
| 1185 | 他死，帝国进入王朝混乱 |
| **1204** | **拉丁人来收账** |

为什么是 1204 不是 1185？1185 年拉丁人没空（教廷与霍亨斯陶芬正较劲），
1204 年来了 —— **恰好是拜占庭最弱的时刻**（伊萨克二世/阿莱克修斯三世/四世接连内乱）。

> **敌视账是一笔押注你衰落的空头。**
> 你强时它不动，你弱的那年连本带利到期。

## 机制改为持续检查

```paradox
# 每月检查，非一次性到期
if = {
    limit = { latin_hostility > 阈值 }
    AND = { 对方总实力 > 我方实力 × 1.3 }
    AND = { 我方处于危机 / 内战 / 虚弱状态 }   # 死账复活条件
    → 触发清算（十字军 / 讨伐 / 洗劫）
}
```

**三条件同时满足才触发** —— 这就是它能潜伏 22 年的原因。

## CK3 缺的那一层

| 系统 | EU4 | CK3 |
|---|---|---|
| 集体怨恨账 | **AE 侵略扩张** | ❌ 没有 |
| 到期机制 | 包围网 | ❌ |
| 触发条件 | 实力对比 | ❌ |
| 个体好感 | opinion | ✅ |
| 民众好感 | — | ✅（per county） |

CK3 有「每个人怎么看你」，有「每个郡的民众怎么看你」，
**但没有「一个文明怎么看你」。**

⇒ `latin_enmity` / `latin_hostility` 本质上是在**给 CK3 补一套信仰/文化层面的 AE**。

## 为什么这是 CK3 的结构性缺口

CK3 的冲突都在个人/家族层面：宣称、密谋、派系、暗杀。
**没有「文明之间的长期怨恨」这个维度** ⇒ 1204 那种账表达不出来，
只能用一个个角色的好感硬凑。

> **CK3 模拟个人，EU4 模拟国家。**
> **而「集体记恨」是国家的属性，不是个人的属性。**

⇒ 要么 mod 补这一层，要么这个题材永远只能用个人恩怨近似。

# 物质基础：宗教是包装，物质是驱动

**2026-11-09 追加。修正 latin_enmity 的性质 —— 它不是宗教账，是物质账。**

## 物质事实：拜占庭把海上地位卖掉了

| 年 | 事件 |
|---|---|
| 1082 | 阿莱克修斯一世给威尼斯巨额商业特权换海军支援（金玺诏书） |
| 之后 | 威尼斯商人免税、设商馆，挤垮本土商人 |
| 1171 | 曼努埃尔一世逮捕全境威尼斯人、没收财产 —— 物质冲突爆发 |
| 1182 | 安德洛尼卡大屠杀 |
| 1204 | 威尼斯（丹多洛）把第四次十字军引向君士坦丁堡，取帝国 3/8 |
| 1261 | 米海尔八世改给热那亚特权换复国 —— **同一笔交易，换买家** |
| 之后 | 加拉塔热那亚区商业上压过首都，帝国关税流失 |

**死亡螺旋**：

```
没海军 → 拿商业特权换保护 → 本土商人被挤垮
      → 关税流失 → 更养不起海军 → 再让渡特权
```

每次「理性」，合起来是亡国。

## 法兰西-奥斯曼同盟（1536）证明宗教是包装

弗朗索瓦一世与苏莱曼结盟，天主教国王与穆斯林苏丹，当时全欧震动。

| | 物质利益 | 能否与「异端」合作 |
|---|---|---|
| **法国** | 不在东地中海；敌人是哈布斯堡 | ✅ 能签 |
| **威尼斯** | **全部家当在东地中海** | ❌ 不能 |

⇒ 宗教立场为物质利益让步 —— **只要让步的人不是被抢的那个**。

## 模型分两层

```
物质位移 material_grievance   ← 真正的驱动（可计算、可谈判、可清零）
        ↓ 被叙述成
宗教怨恨 latin_enmity         ← 表现层（不可谈判、不可清零）
```

| 怨恨性质 | 能谈判 | 能清零 |
|---|---|---|
| 物质（贸易份额/关税/商馆） | ✅ | ✅ |
| 宗教（异端/背教/渎神） | ❌ | ❌ |

**一旦物质冲突被叙述成宗教冲突，退路就没了。**

1439 的困境：物质上可交易（合一换援助），
但 250 年的宗教叙述已使交易在政治上不可能。

## 煽动者罪行的重新定义

之前说安德洛尼卡「花别人的东西赌别人的命」。
更准确：**他把一件可以谈判的事，变成了不可谈判的事。**

```
可谈判 → 有妥协空间 → 有出路
不可谈判 → 只能靠一方灭亡
```

**不可谈判的东西更好用** —— 不能妥协，就永远有票。

> **煽动者真正的罪不是杀了多少人，是让问题变得不可解。**

## 设计含义

```paradox
# 两层记账
material_grievance   # 物质位移：可计算、可谈判、可条约清零
latin_enmity         # 宗教叙述：包装上去后，物质账清零它也留着

if = { 玩家把 material_grievance 叙述为宗教问题（公开谴责异端）
       → latin_enmity +=
       → material_grievance 从此无法通过条约降低    # ★ 锁定
}
```

⇒ 「花掉不减存量」的真正原因：
**不是民意不会消失，是你把可解决的问题变成了不可解决的。**

# 反向用法：玩家宣告置信度（把结算权交回玩家）

**2026-11-09 追加。本机制最好玩的部分。**

## 第三次出现同一模式

| # | 系统原本判断 | 改成玩家宣言 |
|---|---|---|
| 1 | 你对他的好感（隐藏值） | 玩家宣示信任 |
| 2 | 教区继任分层（硬编码） | 玩家选法令等级 |
| 3 | **你的实力够不够（系统算）** | **玩家宣告「我打得过」** |

> **系统不判断你行不行，系统只结算你说了什么、然后发生了什么。**

## 奖励必须超线性

「打赢一场该赢的仗」与「打赢一场所有人都说你打不赢的仗」，政治价值差着数量级。

```paradox
宣告置信度 C（0–100，玩家自选）

立即收益 = C × 系数                    # 合法性/支持/当次成本减免

到期结算:
  A >= C            → 平稳兑现，正常收益
  A <  C 且赢了     → 超额兑现：奖励 = (C − A)² × 系数   ← 逆袭奖金
  A 远小于 C 且输了 → 惩罚 ∝ C
```

```
A=50, C=50, 赢 → 平平无奇
A=50, C=100, 赢 → 传奇
```

**「超额兑现」是设计的灵魂。**
史实：巴西尔二世在克莱迪翁不是「又赢一场」，是**终结了四十年的战争** ——
他挖 15000 只眼睛，因为战争真的结束了。

## 「不宣告」也必须有代价

| 选择 | 短期 | 长期 |
|---|---|---|
| **不宣告**（C 低） | 安全 | **合法性慢性流失**，激进派不满，精英觉得软弱 |
| **宣告中等** | 平衡 | 稳定 |
| **宣告高** | 立刻拿到政治资本 | 违约则身败名裂 |

**不冒险本身就是一种慢性冒险。**
否则理性玩家永远选 C=0，机制死一半。

## 难度因此交回玩家手里

> **数值不需要平衡，因为赌注是玩家自己设的。**

想稳着玩 → 宣告低；想搏一把 → 宣告高。
同一个机制，两种玩法，都是玩家自己选的。

## 安德洛尼卡与巴西尔二世只差一个数

| | 宣告 C | 实际 A | 结果 |
|---|---|---|---|
| 巴西尔二世 | 100 | 100 | **传奇** |
| 安德洛尼卡 | 100 | 20 | **屑人** |

**不是道德差异，是能力与宣告的差值。**

玩家会亲身体会：当宣告 100 而手上只有 20 时，那个选项点下去是有重量的。

## 原则

> **不要阻止玩家冒险，要结算他的冒险。**

系统不该说「你太弱，不能装这个逼」；它该说「行，你说了，那到期见」。
**然后在到期那天，非常公平地算账。**

# 重大发现：原版已有完整的「加冕誓约」系统

**2026-11-09 追加。本设计最该挂靠的宿主。**

## 完整闭环（1.20 实测）

| 环节 | 原版实现 | 位置 |
|---|---|---|
| 仪式 | `coronation` activity | `common/activities/activity_types/coronation.txt` |
| 宣告 | 誓约 20+ 条：reconquest / peace / alliances / purge_pretenders / end_the_struggle / heir_preparation / mend_the_fracture / provide_for_the_warriors / provide_for_the_poor … | `10_ach_oath_modifiers.txt` |
| **赌注大小** | `value_of_oath` = `activity_special_type_progression / 20`（**加冕隆重度**） | `coronation_upgrade_oath_value_effect` |
| 兑现 | `*_oath_decision`（10 条） | `10_ach_oath_decisions.txt` |
| 违约 | `coronation_events.0150`，按 `honest`/`deceitful` 分描述 | `coronation_events.txt:1156` |

**`value_of_oath` 即本设计的「宣告置信度 C」。**

且其来源极妙：**加冕办得越隆重，誓约越重** ⇒ **排场 = 赌注**。
⇒ 「赌注由玩家自设」原版已经实现了。

## 结论：不建系统，加一条誓约

```paradox
oath_of_ecclesiastical_authority = {
    icon = learning_positive
    # 效果依 oath_value 浮动
}

ecclesiastical_authority_oath_decision = {
    # 兑现：通过法令 / 任命 N 位牧首 / 收回 N 个教区
    # 奖励依 oath_value 浮动
}
```

**一条誓约 + 一条决议 + 本地化。其余全靠原版。**

## 但原版缺一样，正是本设计的加强点

`oath_of_reconquest` 的回报是**平**的：

```paradox
martial = 1
legitimacy_gain_mult = 0.15     # 固定值
courtly_opinion = 10
```

原版只区分「完成 / 未完成」，**不区分「轻松完成」与「奇迹般完成」**。

⇒ 我们的加强点：
```paradox
奖励 = base + (oath_value − 实际能力)² × 系数
```

**「宣告 100 / 能力 20 / 却赢了」在原版与「宣告 20 / 能力 100 / 顺手赢」同酬。**
而历史最看重的正是这个差值 —— 巴西尔二世与安德洛尼卡的区别。

## 这是第三次「原版已有」

| # | 发现 | 结论 |
|---|---|---|
| 1 | `investiture_crisis` | 有，语义不符（主权冲突 vs 人事）→ 只借危机层 |
| 2 | `the_christian_church` situation | 有，但东正教是乘客 → 不借 |
| 3 | **`coronation` oath** | **有，语义完全对上 → 直接挂靠** |

⇒ 「先搜原版有没有」不是偷懒，是唯一正确的起点。
   前两次搜了但语义不符所以不借；若不搜，会在第三层重复造轮子。

## 待办：按优先级

### A. `permitted` 清单整治（治根，改动面大）

**问题**：`history/faiths/00_christianity.txt:13-32` 的 `permitted` 里有明显不合基督教语境的信条。

实测分布（`tenet_sanctity_of_nature`）：

⇒ 全游戏唯一被授权「信自然」的基督教分支就是希腊礼/东正教。

**要做的**：逐条过一遍 `permitted`，把不该在基督教池子里的踢出去；

**风险**：这个文件是整个 867 基督教共用的，改动会影响所有迦克墩信徒 + 所有礼。

### B. 漂移模型：标量 → 向量

**问题**：`divergence` 是一个 0-100 的整数，但东西方差异是六维向量
（和子句/教宗首席权/圣餐饼/教士婚姻/炼狱/划十字方向）。

**要做的**：定义一条有名字的轴（如 `toward_rome` / `toward_byzantium`），
给每个信条标注在轴上的位置；漂移时**沿轴移动一格**，而不是从扁平池里随机抽。

**参考**：P社 在文化系统里做对了（ethos + traditions + pillars 组成的特征空间）。

### C. 教义变更流程化（换成 event chain）

**现状**：`random_list` 抽中即生效，无发起者、无裁决、无记录。

**应该是**：

```
发起（牧首/皇帝/修士团体/异端教师）
   -> 传播（发酵期，可复用 pam_tenet_popularity_*）
   -> 裁决（公会议事件：皇帝召集，可选支持/压制）
   -> 结果
       |-- 通过：信条变更 + 写入决议变量（可查）
       |-- 否决：变更不发生；发起方受损，或分裂
```

**现成零件**：

- `detach_rite_to_new_faith`（`pam_effects.txt:6867`，`pam_declare_rite_heresy_effect` 用的）—— 否决→分裂异端
- `on_rite_change` / `on_rite_updated` / `on_rite_edited`（`religion_on_actions.txt:1015 / 715 / 851`）
- `pam_tenet_popularity_*` 系列（PAM 已有的信条普及度）

### D. 皇帝否决权

**问题**：`doctrine_theocracy_temporal`（世俗君主控制教会）管不了教义变更——
这个字段只被 `can_have_realm_priest_puppet_trigger` 用了。

**要做的**：教义变更后向统治者发信（含 HOR），提供两个选项：

| 选项 | 效果 |
|---|---|
| 追认 | 不变更；+虔诚；与礼仪领袖 +好感 |
| 驳回 | 恢复原信条/教义 + `change_rite_divergence` 下调 + 花虔诚 + 与 HOR -好感 |

**门槛**：`government_has_flag = government_uses_imperial_bureaucracy`
或 `rite = { rite_has_doctrine = doctrine_theocracy_temporal }`。

**已经验过的构件**（符号表确认）：

```
every_rite_tenet        [effect, rite]
rite_has_tenet          [trigger, rite]
add_rite_tenet          [effect, rite]
remove_rite_tenet       [effect, rite]
change_rite_doctrine    [effect, rite]
rite_has_doctrine       [trigger, rite]
change_rite_divergence  [effect, rite]   <- 这是让「驳回」真能挡住下次的关键
```

**注意**：`remove_from_variable_list` 在符号表里**不存在**，清空变量列表很麻烦。
建议用「硬编码正统集合 + scripted_trigger 比对」代替缓存。

### E. `rite` 对象拆分（最根本）

**问题**：`rite` 同时承载三样稳定性完全不同的东西：

| 层 | 例子 | 该不该漂 |
|---|---|---|
| 礼仪 | 有酵饼/无酵饼、划十字方向、语言 | **该漂** |
| 纪律 | 教规、婚姻、斋期 | 半可漂 |
| 启示 | 核心信条（使徒所传、七次大公会议） | **不该漂** |

**要做的**：漂移只允许动 doctrine，**禁止动 tenets**。

**依据**：东正教自称 `orthodoxia`（未偏离的正道），七次大公会议之后不再有新教义；
而 843 年的《正统礼典》是年年当众重读的名录——
**东正教没有一个「可以悄悄变的教义」的位置**。

但新信徒实际拿到的是 **`roman_rite`**，等于替罗马扩了教区。

**链条**：

```
传教事件触发
  -> 只改了 faith = christian_faith          （唯一被写入的字段）
  -> rite 靠文化推导
  -> magyar 文化未绑定任何礼
  -> 落回 faith.main_rite
  -> 867 的 main_rite = roman_rite            （history/faiths/00_christianity.txt:3）
  -> 「罗马礼友邦」
```

**三处证据**：

| # | 事实 | 位置 |
|---|---|---|
| 1 | `add_rite_culture` [effect, rite] 存在，**本体脚本零调用** | 符号表有，`common/` 全库无调用点 |
| 2 | `set_character_rite_with_conversion` 只服务于 rite_growth，**不由传教触发** | `00_religion_effects.txt:1216-1219` |
| 3 | `events/` 下加冕/朝圣/巡游/宫廷都有 `set_character_rite`，**传教没有** | 全库 grep |

**所以**：`roman_rite.cultures = { italian roman lombard langobard cisalpine }`
是全游戏**唯一**填了的礼-文化绑定（另一个是犹太教阿什肯纳兹）。
其余所有礼的 `cultures` 都是空的 → 所有皈依者要么落进 `roman_rite`，要么成为动态礼。

**根因（一句话）**：

> **「谁把你带进来的」这个变量，在数据模型里没有位置。**
> 皈依是一个**关系事件**，被建模成了**属性赋值**。

对照真实历史里决定归属的要素：

| 真实决定因素 | 游戏字段 |
|---|---|
| 谁给你施洗 | ❌ 无 |
| 谁为你按立主教 | ❌ 无 |
| 礼仪用哪种语言 | ❌ 无 |
| 你归哪个都主教区 | ⚠️ `clerical_region`（管地不管人） |
| **你的文化** | ✅ 只有这个 |

**为什么大摩拉维亚能解释、马扎尔不能**：

| | 归拉丁的实际原因 | 游戏能否表达 |
|---|---|---|
| 大摩拉维亚 | 美多德 885 年死，弟子被逐，弗兰克教士接管**既有教区** | ✅ 地理 + `clerical_region` |
| 马扎尔 | **皇帝亲自派的廷臣、自己的钱** | ❌ 完全无法表达 |

同一条链，一个说得通、一个说不过去——**区别就在「渠道」这一个变量上**。

**最小修法**（不需要新系统，只需要接线）：

```
convert(目标, 目标信仰, 来源 = 传教者的礼)
  if 来源存在 -> set_character_rite_with_conversion = 来源.rite
  else        -> 落回文化默认（现状）
```

**引擎原语全部现成**：

```
set_character_rite                 [effect, character]
set_character_rite_with_conversion [effect, character]   <- 带皈依语义，正是为这个造的
add_rite_culture                   [effect, rite]        <- 绑定文化，本体零调用
on_faith_conversion                [on_action]
```

**结论**：这不是「设计不够深」，是「**零件全在，线没接**」。
而因为这套脚本没有编译期检查，没接的线不会报错——
**它只会安静地把你的人算到对面去。**

# 荒谬总览：现有宗教机制的建模缺陷

**建档**：2026-11-10
**缘起**：一场 867 拜占庭存档的实机排查。以下每一条都有文件 + 行号可核。
**用途**：宗教系统大改的病因诊断。待办清单见下一节。

## 一、七次「faith 是唯一粒度」

`rite` 这一层建了，但只在三处生效：**图标、`rite_has_doctrine`、`rite_has_parameter`**。
除此之外，所有「判断这些人是谁」的地方，都只看 `faith`。

| # | 场合 | 判据 | 后果 |
|---|---|---|---|
| 1 | 圣物归属 | `is_holy_relic_for = faith` | 伦巴第主教制的权杖，希腊礼永远用不了也清不掉 |
| 2 | 信条抽卡池 | `christian_faith.permitted` | 希腊礼可采纳「圣洁自然」 |
| 3 | 大公会议资格 | 傀儡代替召集权 | 罗马皇帝要先有傀儡才能开会 |
| 4 | 大公会议地点 | `county.holder.faith ?= host.faith` | 科隆主教可在安条克开大公会议 |
| 5 | 教宗选举通知 | `every_faith_character` | 拜占庭皇帝收到「我们有教宗了」 |
| 6 | 礼的归属 | 全游戏仅 `roman_rite` 有 `cultures` | 马扎尔/亚美尼亚皈依即归罗马礼 |
| 7 | 礼仪领袖 | `head_of_rite` 挂在 `faith_details` 上 | 教宗是全 `christian_faith` 的礼仪领袖，含希腊礼 |

## 二、五次「你的行动不进入因果链」

| 你做的 | 系统记的 | 结果 |
|---|---|---|
| 派传教士给马扎尔人 | `faith = christian_faith` | 归了罗马礼 |
| 打下安条克 | 一个 county | 教会管辖不变（`clerical_region` 是静态数据） |
| 打下罗马城 | 一个 county | 教宗仍是 `k_papal_state` 持有者，仍是礼仪领袖 |
| 把教宗打成封臣 | 一份封建契约 | 「不算控制」，决议只认 `puppet:` |
| 召集大公会议 | 一次活动记录 | 大分裂进度照涨（独立状态机） |

**唯一做对的反例**：

> 「观察你的骑士实践某信条后，你藉此了解了这一信条。」

**因为它记了「谁 → 从谁那儿 → 学到了什么」。**

⇒ **只要记录「渠道」，if 线会自己长出来。**

## 三、控制词汇表：只有个人，没有制度

| 引擎有的 | 性质 |
|---|---|
| vassalage | 个人 |
| puppet | 个人 |
| hook | 个人 |
| dynasty | 个人 |

**没有「编制」。**

而拜占庭控制教会的真实手段，全是制度性的：

| 手段 | 性质 | 史例 |
|---|---|---|

| 立法约束修院 | 立法 | 尼基弗鲁斯二世 964 年新律 |

**查士丁尼《新律》第 6 篇序言**：

> 「神从天上赐给人类两样最大的恩惠：**祭司职**与**帝权**。」两者应当和谐运作。

>
> «Maxima quidem in hominibus sunt dona dei a superna collata clementia **sacerdotium et imperium**,

> ex uno eodemque principio utraque procedentia humanam exornant vitam.»
>
> —— *Nov.* 6 praef.（*Authenticum* 传本，Schoell–Kroll 编校本）

> **希腊文**：另有希腊传本（168 部希腊新律汇编），本仓库**尚未取得校勘本希腊文**，故不转录 —— 见文末附二。
>

**两个部门，一个秩序。** 而引擎的词汇表里没有「关系」这个词。

## 四、政治问题被翻译成数值问题

| 政治问题 | 数值代理 |
|---|---|
| 皇帝对教会是否说得上话 | `piety_level >= very_high_piety_level` |
| 是否够格阻止大分裂 | 5 选 4：虔诚 + 圣地×2 + 立场 flag + 教士支持 7 |
| 教宗选举在哪举行 | `[new_pope.GetCurrentLocation.GetName]` |
| 教义变更的正当性 | 一个 4%/年的骰子 |
| 谁配当礼仪领袖 | 谁持有 `k_papal_state` 这个头衔 |

**而可刷的数值，就不再是政治。**

### 反证：尼基弗鲁斯二世（963-969）

| 年 | 事 |
|---|---|
| 961 | 收复克里特 |
| 964 | **颁布新律：禁止新建修道院、禁止向修院捐赠土地** |
| 965 | 收复塞浦路斯、奇里乞亚 |
| 969 | 收复安条克；同年被刺杀 |

他与牧首波利欧克图斯的冲突（二婚）：牧首拒绝主持 → 宫廷教士代为主持；
牧首禁止他进圣索菲亚 → **他做了苦修** → 回去继续当皇帝、继续立法。

> **中世纪是摩擦：互相拉扯、各自让一步、事情继续往前走。**
> **不是服从，也不是打卡。**

## 五、引擎的世界观：羊皮纸匮乏的拉丁西方

**傀儡** = 同一约束下唯一可行的隶属表达。

⇒ **引擎是按「纸不够用」那一档做的；而拜占庭是「贵但做了」那一档。**
**所以它对拜占庭水土不服——不是因为拜占庭特殊，是因为它有编制。**

## 五个可借鉴的结构

### 1. 教会 = 基层服务节点（原文 §1.3，第 17 行）

> 教会是帝国行政体系的组成部分，而非独立的政治实体。
> 神父负责登记出生、死亡、婚姻、财产变动；牧首区主持官修信史；
> 教会学校提供基础教育，筛选地方人才进入官僚系统。

⇒ 对应缺口：引擎只有 vassal / puppet，**没有「部门」这个范畴**。

### 2. 四分法：四大独立且互锁的支柱（§1.4，第 25 行）

| 系统 | 核心职能 | 与中央的关系 |
|---|---|---|
| 军区制 | 国防、农兵动员、边境维稳 | 接受最高军事指挥部指令 |
| 教会系统 | 基层治理、超自然事件、意识形态 | **接受牧首区和皇帝的双重领导** |
| 司法系统 | 民事、刑事、跨教区案件 | 适用统一罗马法，法官独立于教会 |
| 财税系统 | 税收、国库、预算拨付 | 独立，受中央财政司监督 |

⇒ 对应缺口：**「双重领导」这种关系，引擎无法表达。**
它只有单向的「谁是谁的封臣」。

### 3. 三级结构（§6.1，第 221 行）

> 堂区（驻堂神父）→ 主教区（主教）→ 军区（军区将军/总督）
> 每一级都配置了行政、财税、军事和司法的对应职能。

⇒ 对应缺口：引擎只有「头衔」，**没有「层级 + 职能」**。

### 4. 皇帝与教会的关系（§5.9，第 208 行）

> 皇帝任命牧首，但**不直接干预教义裁定**。
> 皇帝**有权召开大公会议**讨论神学议题，但**裁决结果由教会议定**。

⇒ **这与本档案「荒谬总览」的结论完全一致**，也是 754/787 圣像破坏运动的实际结构：
754 年皇帝召集的会议被后世判为伪公会议；787 年的被承认为第七次大公会议。

### 5. 记录的可信性（§7，第 248 行）

三色墨水时间戳系统：

| 墨水 | 颜色变化 | 时间尺度 |
|---|---|---|
| 鞣酸铁（蓝黑） | 浅蓝灰 → 深黑 | 数十年 |
| 铁卟啉（红） | 浅红 → 深红/褐 | 十余年 |
| 镁卟啉（绿） | 浅绿 → 金黄 | 数年至十余年 |

⇒ 这与「蜡封 = 低识字率下的验签补丁」是**同一个问题的两代解法**：

| 方案 | 原理 | 前提 |
|---|---|---|
| 蜡封 | 物理完整性（拆开即毁） | 没有可靠的签名体系 |
| 三色墨水 | 化学衰变速率（不可伪造的时间戳） | 有纸、有化学 |

⇒ 对应缺口：**引擎没有「记录」这一层。** 教义变更只留一行 `debug.log`。
