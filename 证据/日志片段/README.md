# 证据 · 日志片段

这个目录放**可公开的日志摘录**，用来支撑各章结论。

## 为什么是摘录，不是原始日志

| 原因 | 说明 |
|---|---|
| 体量 | 单个 `error.log` 可以是几十 MB，其中 99% 是与结论无关的重复行 |
| 个人数据 | 原始日志含本机绝对路径、用户名、mod 清单 |
| 时效 | 日志会在下次启动时被覆盖/轮转，原文件早已不存在 |

⇒ 所以这里给的是**当时从原文件里摘出来的行**，并保留：时间戳、源文件:行号、错误文本。
这三样是复现与核对的关键，其余（路径、账号）一律替换为占位符。

## 脱敏规则

| 原始 | 这里 |
|---|---|
| 本机绝对路径（Windows 盘符 / WSL `/mnt`） | `<游戏目录>` / `<用户目录>` / `<mod 目录>` |
| 个人 mod 名与内部文件名 | `<本地 mod>` / `<文件>` |
| 第三方 mod 的具体文件名 | 保留相对路径（那是定位信息），必要时缩写 |
| 用户名 / 账号 / 好友码 | 一律不出现 |
| workshop id | **保留**（公开标识，且是定位 mod 的唯一稳定键） |

## 一条纪律

> 摘录只保留**技术行**。任何含绝对路径、用户名、账号的行都不进这个目录。
> 如果某条结论只能靠「含个人信息的那一行」支撑，那这条结论就不该公开。
