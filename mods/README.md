# mods/ —— 上游名字包的兼容性修正

> 这里放的是**修正版**，不是一个 mod。每个子目录独立可装，互不依赖。
> **所有条目的原始内容版权归各自作者**；本仓库只主张「适配改动」这一部分。

## 为什么会有这个目录

Stellaris 从 **v3.6** 起改了「编号占位符」机制，**同时改了三件事**。任何一件踩中都会**静默失效**：
不报错、不弹窗，名字就是不对。

| 项 | 3.6 之前 | 3.6 之后 |
|---|---|---|
| 语法 | `%O%` `%R%` `%C%` | `$C$` `$ORD$` `$R$` `$HEX$` |
| 载体 | 写在 `common/name_lists` 里 | **必须写在 localisation 的字符串里** |
| 字段 | 任意 | **只有 `fleet_names` / `army_names`** |

于是 3.6 之前的老名字包会以三种方式坏掉：

```text
① 内容锁在 .zip 里      引擎不解压 -> 整个包从未生效过（最常见）
② 编号写成 %R%          语法过时      -> 名字里直接出现字面的 %R%
③ 编号写在 name_lists   载体过时      -> 同上，且更难查
```

## 怎么装

**本目录不提供 `.mod` 描述文件。**
用 Paradox Launcher 的「创建 Mod」按钮生成一个，把 `path` 指到对应子目录即可。
手写也就四行：

```
name="<任意名字>"
path="<该子目录的绝对路径>"
supported_version="v4.6.*"
version="1.0"
```

> 注意 `path` 用绝对路径，反斜杠写双反斜杠或直接用正斜杠。
